# KAAVAAK — اطلس دانش هوافضا و هوانوردی

نسخه 0.2.0 | دامنه جامع

KAAVAAK کتابخانه‌ای ساختاریافته برای تمام خانواده‌های هواگرد و سامانه‌های فضایی است: هواپیماهای تجاری و عمومی، نظامی، آموزشی و آزمایشی، بالگرد، گلایدر، هواگرد سبک‌تر از هوا، پهپاد، eVTOL، ماهواره، فضاپیما، پرتابگر و زیرساخت زمینی.

## وضعیت نسخه
این نسخه پایه شامل معماری دانش، نقشه آموزشی، طبقه‌بندی پلتفرم‌ها، رجیستر منابع رسمی، رجیستر استانداردها، فهرست پروژه‌های متن‌باز و رویه کنترل اسناد است. این نسخه **آرشیو کامل PDFهای دانلودشده نیست**؛ فایل‌های حجیم FAA در محیط اجرای فعلی دریافت نشدند. هیچ فایل خارجی را دانلودشده یا اعتبارسنجی‌شده معرفی نمی‌کنیم مگر اینکه فایل، اندازه، قابلیت بازشدن و SHA-256 آن ثبت شده باشد.

## اصول اصلی
- دانش مشترک یک‌بار ثبت شود؛ الزامات و گواهی‌نامه‌های هر پلتفرم مستقل باقی بماند.
- هر سند ناشر، شناسه، ویرایش، تاریخ، حوزه کاربرد، مجوز، URL، وضعیت و SHA-256 داشته باشد.
- استانداردهای پولی/دارای حق نشر و اسناد کنترل‌شده بدون مجوز بازنشر نمی‌شوند.
- منابع آموزشی جایگزین داده طراحی تأییدشده، AMM/SRM/IPC کنترل‌شده یا مقررات جاری نیستند.

## مرز ایمنی و انطباق
KAAVAAK مرجع آموزشی/پژوهشی است و به‌تنهایی سامانه تأیید طراحی، برنامه نگهداری مصوب، داده تعمیراتی مجاز یا مجوز پرواز نیست. برای تصمیم‌های صلاحیت پروازی باید از داده جاری و تأییدشده مرجع صلاحیت‌دار و افراد مجاز استفاده شود.
